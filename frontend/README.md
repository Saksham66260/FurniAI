# FurniAI frontend

React + TypeScript storefront for the FurniAI demo. It includes natural-language search, ranked results, product knowledge, cart and checkout flows, and a conversational AI assistant.

```bash
npm install
cp .env.example .env.local
npm run dev
```

The app reads `VITE_API_URL` and defaults to `http://localhost:8000`.

Useful scripts:

```bash
npm run build
npm run lint
npm run preview
```
